# M3 tool

A free reference site for BMW M3 owners and shoppers: factory spec, real aftermarket parts with
dated prices, build costs and maintenance. Nothing is for sale and there are no store links.

Independent fan project. Not affiliated with, endorsed by, or sponsored by BMW AG. BMW and M3 are
trademarks of BMW AG, used here only to describe the cars.

## Status

Work in progress. Phase 0A is laying the foundations: the site skeleton, the data and 3D asset
contracts, CI and the project standards. The site is `noindex` until the public beta.
